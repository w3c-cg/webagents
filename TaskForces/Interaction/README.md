# Interaction

**Moderators:** Amit K. Chopra, Samuel H. Christie,  Matteo Baldoni, and Munindar P. Singh

## Description

We define a multiagent system as one where the agents represent autonomous real-world principals and interact on their behalf. Interaction protocols help give structure to the interactions in a multiagent system. Our purpose is to articulate the conceptual requirements for interaction protocols and the resulting system architecture. We will discuss how well ongoing efforts in academia and industry address the requirements with the aim of informing standardization efforts in the area of multiagent interaction protocols.

## Expected Outcome

A CG group report on requirements for multiagent interaction on the Web.
